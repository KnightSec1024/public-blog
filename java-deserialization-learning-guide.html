安全学习 · Java Deserialization

Java 反序列化漏洞学习环境推荐

按「入门 → 进阶 → 精通」排序，全部支持 IDEA 断点调试，跟完即可看清 POC 从字节流到 RCE 的完整解析链

1WebGoat — 官方交互式教学 最适合入门

仓库：https://github.com/WebGoat/WebGoat

  • OWASP 官方靶场，自带 Insecure Deserialization 专题课程
  • 每一步有提示引导，最终目标是构造 gadget 让服务器 sleep 5秒（安全的 RCE 等价物）
  • 内置 Gadget Chain 概念讲解（VulnerableTaskHolder 链）

启动方式

git clone https://github.com/WebGoat/WebGoat.git
cd WebGoat && mvn spring-boot:run
# 浏览器访问 http://localhost:8080/WebGoat

调试要点：在 org.dummy.insecure.framework.VulnerableProcessingHolder#readObject 下断点，观察恶意序列化数据如何在反序列化时被自动触发。

2java-sec-code — 漏洞代码集合 最适合跟单链

仓库：https://github.com/JoyChou93/java-sec-code

  • 覆盖原生反序列化、fastjson、SnakeYAML、Jackson、SnakeXML 等多种触发点
  • 每个漏洞接口单独一个 Controller，代码极简，直接发包即可触发
  • 附带 CVE 列表和利用说明

启动方式

git clone https://github.com/JoyChou93/java-sec-code.git
# 导入 IDEA（Maven 项目），运行 WebSecCodeApplication

调试步骤（原生反序列化为例）

  1. POST /deserialize 发送 base64 序列化数据
  2. 在 ObjectInputStream#readObject 下断点
  3. F7 跟进 → ObjectInputStream#readOrdinaryObject → readSerialData → 反射调用目标类的 readObject
  4. 观察 gadget 类（如 CommonsCollections 的 TransformedMap）如何一步步走到 Runtime.exec

3ysoserial + 本地 CommonsCollections 靶场 核心必学 ★

ysoserial 仓库：https://github.com/frohoff/ysoserial

学反序列化绕不开 CommonsCollections 链。建议自建一个最简靶场专门调试。

靶场代码（自己写一个 20 行的服务端）

// VulnServer.java — 接收序列化数据并反序列化
public static void main(String[] args) throws Exception {
    ServerSocket server = new ServerSocket(8888);
    Socket socket = server.accept();
    ObjectInputStream ois = new ObjectInputStream(socket.getInputStream());
    ois.readObject(); // ← 在这里下断点
}

生成 Payload

# 下载 ysoserial-all.jar 后
java -jar ysoserial-all.jar CommonsCollections6 "open -a Calculator" > payload.ser

调试路径（CC6 链，面试/工作最常见的链）

断点位置观察内容
ObjectInputStream#readObject入口
AnnotationInvocationHandler#readObject反序列化时自动回调的 readObject
AbstractMapDecorator#equals → LazyMap#get触发 map.get 的关键一跳
ChainedTransformer#transform链式执行开始
InvokerTransformer#transform反射调用任意方法，最终 Runtime.exec
跟完这条链你会彻底理解「反序列化漏洞 = readObject 回调 + 可达的危险方法调用链」。

🛠通用调试技巧

  1. IDEA 断点技巧：在 ObjectInputStream#readObject0 下断点后，用 Evaluate Expression 实时查看当前解析的类名（desc.getName()）
  2. 看调用栈比单步快：触发 payload 后直接看左下角 Frames 面板，从底向上读就是完整利用链
  3. Method Breakpoint：在 Runtime#exec 下方法断点，反推谁调用了它，一条调用栈即一条可利用链
  4. 序列化数据分析：用 zkar 解析 payload 字节流，对照 Java 序列化协议规范 看每个 TC_OBJECT / TC_CLASSDESC 标记的含义
